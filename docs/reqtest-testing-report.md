# Тестування програмної системи «Готель» у Reqtest

## 1. Мета роботи

Мета роботи — здійснити тестування програмної системи «Готель» в інструменті Reqtest з урахуванням завдань, сформульованих у проєкті, навчальних матеріалів та підходів до управління вимогами і тестуванням програмного забезпечення.

---

## 2. Короткі теоретичні відомості

Reqtest — це інструмент для управління вимогами, тест-кейсами, тестовими запусками та результатами тестування.

У процесі тестування програмного забезпечення важливо не лише перевірити роботу функцій, а й забезпечити зв’язок між вимогами, тест-кейсами та результатами виконання тестів.

Для цього у Reqtest можна:

- створювати вимоги;
- створювати тест-кейси;
- пов’язувати тест-кейси з вимогами;
- створювати тестові запуски;
- виконувати тести;
- фіксувати результати виконання;
- аналізувати покриття вимог тестами.

Офіційний ресурс Reqtest:  
https://reqtest.com/en/features/test-management/

---

## 3. Опис програмної системи

Для тестування було використано навчальний проєкт **«Програмна система “Готель”»**.

Система призначена для автоматизації базових процесів роботи готелю:

- перегляд списку номерів;
- перегляд інформації про номери;
- пошук і фільтрація номерів;
- створення заявки на бронювання;
- перевірка введених даних;
- збереження заявки;
- перегляд списку бронювань;
- перевірка сумісності з браузером.

---

## 4. Підготовка вимог у Reqtest

У Reqtest було створено набір вимог для проєкту **System-Hotel Requirements Testing**.

Основні функціональні вимоги:

| ID | Назва вимоги | Призначення |
|---|---|---|
| FR-01 | View rooms | Перегляд номерів готелю |
| FR-02 | View room details | Перегляд детальної інформації про номер |
| FR-03 | Create booking request | Створення заявки на бронювання |
| FR-04 | Validate input data | Перевірка введених даних |
| FR-05 | Save booking request | Збереження заявки на бронювання |
| FR-06 | View booking list | Перегляд списку бронювань |
| FR-07 | Change booking status | Зміна статусу бронювання |
| FR-08 | Edit room information | Редагування інформації про номер |
| FR-09 | Search and filter rooms | Пошук і фільтрація номерів |

Нефункціональні вимоги:

| ID | Назва вимоги | Призначення |
|---|---|---|
| NFR-01 | Usability | Зручність використання системи |
| NFR-07 | Browser compatibility | Сумісність системи з браузерами |

## 12. Висновок

У результаті виконання роботи було здійснено тестування програмної системи **«Готель»** в інструменті Reqtest.

У Reqtest було створено вимоги до системи, підготовлено тест-кейси, деталізовано тест-кейс для створення заявки на бронювання, встановлено зв’язок між вимогою та тест-кейсом, а також виконано тестовий запуск.

Результати тестування показали, що основні функції системи працюють коректно. Усі тест-кейси тестового запуску отримали позитивний результат. Це підтверджує працездатність основних функцій програмної системи «Готель» та демонструє практичне використання Reqtest для управління вимогами і тестуванням.
