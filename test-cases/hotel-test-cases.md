# Тест-кейси програмної системи «Готель»

## Мета

Цей файл містить перелік тест-кейсів, створених для перевірки програмної системи «Готель» у Reqtest.

Тест-кейси охоплюють основні функції системи: перегляд номерів, створення бронювання, перевірку вхідних даних, збереження заявки, пошук і фільтрацію номерів, а також сумісність із браузером.

---

## Список тест-кейсів

| ID | Назва тест-кейса | Пріоритет | Мета перевірки | Очікуваний результат |
|---|---|---|---|---|
| TC-01 | View rooms list | High | Перевірити відображення списку номерів | Система відображає список номерів з типом, ціною та статусом |
| TC-02 | Create booking request | High | Перевірити створення заявки на бронювання | Заявка на бронювання створюється після введення коректних даних |
| TC-03 | Validate input data | High | Перевірити валідацію вхідних даних | Система не дозволяє створити заявку без обов’язкових даних |
| TC-04 | Save booking request | High | Перевірити збереження заявки на бронювання | Створена заявка зберігається у системі |
| TC-05 | Search and filter rooms | Medium | Перевірити пошук і фільтрацію номерів | Система відображає лише номери, що відповідають умовам пошуку |
| TC-06 | Browser compatibility and usability | Medium | Перевірити роботу системи в браузері та зручність використання | Система відкривається і працює коректно у сучасному браузері |

---

## Деталізація тест-кейса TC-02

### Назва

TC-02 Create booking request

### Опис

Тест-кейс перевіряє, чи може користувач створити заявку на бронювання номера за допомогою форми бронювання.

### Передумова

Форма бронювання відкрита у програмній системі «Готель».

### Кроки тестування

| Крок | Дія | Очікуваний результат |
|---|---|---|
| 1 | Ввести повне ім’я клієнта | Ім’я клієнта введено успішно |
| 2 | Ввести номер телефону клієнта | Номер телефону введено успішно |
| 3 | Ввести email клієнта | Email введено успішно |
| 4 | Обрати дату заїзду та дату виїзду | Дати вибрано успішно |
| 5 | Ввести номер кімнати | Номер кімнати введено успішно |
| 6 | Натиснути кнопку бронювання | Система створює заявку на бронювання |
